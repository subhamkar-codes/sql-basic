# SQL Basics

MySQL scripts I wrote while learning SQL: creating tables, inserting data, keys, joins, unions and more. Each script builds on the one before it.

## Scripts

| File | Concept |
|---|---|
| `01_create_table.sql` | Creating a database and tables |
| `02_insert_data.sql` | Inserting sample data |
| `03_alter_table.sql` | Changing a table with `ALTER TABLE` |
| `04_foreign_key.sql` | Foreign keys and relationships between tables |
| `05_joins.sql` | Joining tables |
| `06_union.sql` | Combining results with `UNION` |
| `07_functions.sql` | Built-in SQL functions |
| `08_delete_vs_drop.sql` | Difference between `DELETE` and `DROP` |
| `09_log_table.sql` | Creating a log table |

## Concepts covered

- Creating tables and inserting data
- Changing table structure
- Foreign keys
- Joins and `UNION`
- Functions
- `DELETE` vs `DROP`

## How to run

1. Install MySQL and open MySQL Workbench (or the command line).
2. Run the scripts in order, starting from `01_create_table.sql`.
